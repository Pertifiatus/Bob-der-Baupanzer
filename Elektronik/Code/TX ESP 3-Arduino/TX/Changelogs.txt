TX Changelogs
=============

TX-V0:
------
- Erster Test-Sketch für den TX-ESP32
- CRSF Library eingebunden für Crossfire-Empfaenger
- RX auf GPIO6, TX auf GPIO5
- Liest alle 16 Kanäle vom Empfänger
- Gibt alle Kanäle auf dem Serial Monitor aus
- TXSerial auf 9600 Baud (noch nicht benutzt)
- Nur zum Testen ob die CRSF-Verbindung funktioniert

TX-V1:
------
- Richtiges Kommunikations-Protokoll eingebaut!
- Verschiedene Start-Tokens für verschiedene Empfänger:
  * 0x01 für ESP32 (14 Kanäle)
  * 0xA1 für Arduino 1 - Motor (7 Kanäle)
  * 0xA2 für Arduino 2 - Greif (6 Kanäle)
  * 0xA3 für Arduino 3 - Zange (3 Kanäle)
- Alle 50ms wird an jeden Empfänger gesendet
- Werte werden von CRSF (172-1810) auf 0-1000 gemappt
- constrain() sorgt dafür dass Werte im Bereich bleiben
- TXSerial auf 115200 Baud, RX=20, TX=21

TX-V2:
------
- Kanal-Anzahl für A1 von 7 auf 6 reduziert
- Kanal-Anzahl für A2 von 6 auf 8 erhöht

TX-V3:
------
- Kanal-Anzahl für A3 von 3 auf 8 erhöht

TX-V4:
------
- "Failsave Modus" hinzugefügt, wenn alle Kanäle auf 0 sind, sendet der ESP keine Daten mehr an die Geräte, sodass diese in den    Failsave Modus gehen, anstatt alle Motoren schnell zu drehen

TX-V5.2:
--------
- CRSF-Library überarbeitet (kompatibel, gleiche read()/update()-Funktionen):
  * Wartet auf Sync-Byte (0xC8) statt jeden Byte-Anfang als Frame zu nehmen
    -> kein dauerhaftes "Verrutschen" mehr nach einem verlorenen Byte
  * Längen-Byte wird geprüft, CRC8 (Polynom 0xD5) wird geprüft -> kaputte
    Frames werden verworfen statt als Kanalwerte durchzugehen
  * Kanal-Frame nur noch bei korrekter Länge (24) dekodiert (vorher "< 14")
  * Link-Statistik (Frame 0x14) wird ausgelesen: LQ, RSSI, SNR, TX-Power ...
  * Neue Funktionen: isLinkUp(), msSinceLastChannels(), linkQuality(),
    rssi(), snr(), linkStats(), crcErrors()
- Failsafe neu: statt "alle Kanäle == 0" jetzt Timeout (250 ms ohne gültigen
  Kanal-Frame) oder LQ == 0. Der alte Check hat nach einem Verbindungsverlust
  NIE ausgelöst, weil die letzten Kanalwerte stehen geblieben sind.
- Optional LQ_MIN für Failsafe bei schlechter Verbindung
- Debug-Ausgabe zeigt LQ/RSSI/SNR/CRC-Fehler, ist auf 200 ms gedrosselt und
  läuft auch im Failsafe
- Protokoll zu ESP32/A1/A2/A3 unverändert -> Boards brauchen kein Update
